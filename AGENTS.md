# Agent Guidelines

## Project Guidelines

Follow the repository guidance documents listed here unless the user explicitly directs otherwise.

- `docs/repo-philosophy.md` - repository design philosophy for build layering, C++/Python ownership boundaries, dependency provisioning, environments, packaging, and CI.

## Conflict Policy

If a requested change conflicts with these guidelines, stop before implementing and call out the conflict clearly.

Then resolve it by doing one of the following:

- Adjust the requested change so it follows the guidelines.
- Make an explicit exception and document it near the affected decision.
- Update the relevant guideline document if the intended repository policy has changed.

Do not silently override the guidelines, and do not treat them as more specific than the user's explicit instruction.
